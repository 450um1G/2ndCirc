## 💬 How to submit comments

**You can view and download all files above without a GitHub account.** A
free account is needed only if you want to post comments.

All discussion goes through **GitHub Issues** — same convention as the
1st Circulation. Please use GitHub Issues rather than direct email whenever
possible: email threads are easy to lose, miss delivery, or bury, whereas
GitHub Issues keep the record reliable and shared. If GitHub access becomes
a serious obstacle, please contact the corresponding author.

1. **Open the comments page** — click the **"Issues"** tab near the top of
   this page, then open the single pinned comments issue.
2. **Post your comment.** You will be prompted to sign in. If you do not have
   a GitHub account yet, the prompt also lets you sign up — it is free, and
   only requires an email and a username.
3. **Use paper-label prefixes** for paper-specific comments:
   `[Paper T]`, `[Paper S1]`, or `[Paper S2]`. Comments without a label are
   assumed to apply to all three.

Comments posted to this repository are publicly visible.

## ✍ Author information — new contributors and updates

If you commented on the 1st Circulation but are **not yet listed in the
author block** of the three papers and wish to be added:

➡ **[Open an "Author Information Submission" issue](../../issues/new?template=author-info.yml)**
by **Mon 8 June 2026**.

If you are already listed as an author but need to update your affiliation,
ORCID iD, email address, or contribution statement, please use the same form.

The form asks for name, ORCID iD, primary affiliation, optional additional
affiliations, email address (required for AAS journal submission), and an
optional contribution statement. Please write your entries in AASTeX form,
as in this example:

```latex
\author[0000-0002-0786-7307]{Ray S.~Furuya}
\affiliation{Institute of Liberal Arts and Sciences, Tokushima University, Minami Jousanjima-Cho 1-1, Tokushima, Tokushima 770-8502, Japan}
\affiliation{Visiting Associate Professor, Center for Computational Astrophysics (CfCA), National Astronomical Observatory of Japan (FY~2023), Osawa 2-21-1, Mitaka, Tokyo 181-8588, Japan}
```

Use `~` for non-breaking spaces between initials and given names; one
`\affiliation{...}` line per affiliation; escape special characters as in
`Christine Andr\'e` for "André" or `Fran\c{c}oise Combes` for "Françoise".
